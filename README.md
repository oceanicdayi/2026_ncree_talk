# 淡江大橋演講紀錄

國家地震工程研究中心陳俊中博士於 2026 年 10 月 22 日演講「Danjiang Bridge: An Introduction」之中文整理頁。

## 本機預覽

直接以瀏覽器開啟 `index.html`。網站不依賴外部套件或建置流程。

## GitHub Pages

網站以 GitHub Actions 發佈 Pages。若此 repository 尚未啟用 Pages，請在 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。

演講數值以投影片照片可辨識內容為準；照片為現場紀錄。
