Talk 04 · Field Reconnaissance

地震災情勘查
與資料平台

第二場新增演講｜依投影片整理震後建築勘查的分階段流程、平台設計目標、行動調查表、建物損害分級與 A02 詳查案例。講者姓名未能從現有照片辨識，故不臆測補列。

現場調查資料平台損害分級

勘查工作分階段

收集災損資訊

第一階段：在災後收集建築與設施受損資訊。

詳細調查受損建物

第二階段：對受損建築進行詳細勘查，記錄構件、損害程度及現場狀況。

勘查資料應用

第三階段及後續：將勘查成果提供應變中心、研究與災害管理系統使用。

建置平台的目標

現場效率

使用智慧裝置有效率地收集災害損害資料。

任務與團隊管理

透過網路管理勘查任務與調查隊伍。

一致資料格式

讓調查資料以一致格式收集，便於整合分析。

即時呈現

即時將調查結果呈送應變中心。

系統介接

使用 Web Services API 分享資料給其他災害管理系統。

平台架構與資料流

投影片架構包含：調查支援管理系統、勘查資料庫、資料收集伺服器、災害調查 Web 應用程式、iOS／Android 行動應用程式、勘查支援隊伍、調查人員、應變隊伍與研究人員，以及災害資訊 WebGIS 服務。行動端收集資料後送至伺服器和資料庫，再供應變與研究端查詢、呈現及分享。

行動調查表收集的欄位

  • 調查對象主類別、子類別與名稱。
  • 損害的一般描述、損害程度、對象狀況。
  • 附加影片與照片。
  • 設定 GPS 座標位置。

建物資料紀錄

投影片以 ACI 133 Reconnaissance Activities 指引展示建物調查紀錄表，涵蓋第一層平面圖、方位與位置、結構類型、興建年代、地上樓層與高度、RC 結構及砌體牆損害等級、永久層間變位、觀察紀錄與照片。檢核項目還包括挑出、柱尺寸、短柱、軟弱層、偏心與是否補強。

損害分級：五級尺度

建物整體使用無害、輕度、中度、嚴重、崩塌五級；構件也以 I 至 V 級記錄。下表為投影片重點的文字整理。

RC 柱與梁

I輕微裂縫
II剪力裂縫 ≥0.3 mm、混凝土粉刷層剝落
III混凝土保護層剝落，鋼筋未外露，箍筋未開裂或斷裂
IV保護層脫落範圍大，部分箍筋外露或斷裂，主筋可能挫屈
V箍筋脫開或斷裂，主筋挫屈嚴重，核心混凝土脫落，可能樓層下陷

RC 牆

級別投影片描述重點
I輕微裂縫；水平裂縫寬度在 0.3 mm 以下。
II水平裂縫延伸至柱，或有斜向裂縫；裂縫寬度 0.3–0.5 mm。
III出現斜向裂縫，部分保護層混凝土剝落，但未見牆內主筋。
IV大量斜向裂縫；可見牆內主筋但未拉斷，邊柱保護層脫落。
V斜向裂縫擴大、牆內主筋拉斷；邊柱鋼筋挫屈，混凝土碎裂剝落，樓版下陷。

砌體牆

級別投影片描述重點
I無裂縫或牆體灰縫出現裂縫，裂縫寬度 ≤1 mm。
II裂縫寬度 1–10 mm，牆體常見磚塊劈裂。
III裂縫寬度 >10 mm，或可見穿孔，常見磚塊擠碎。
IV大量磚塊擠碎，邊柱有嚴重剪力破壞。
V牆體擠碎崩落、邊柱錯位，樓層沉陷。

A02 詳細調查案例

投影片案例標記為 A02，展示建物外觀、第一層平面調查紀錄與受損構件照片。後續投影片將 RC 牆與砌體牆損害均標示為 IV 級；照片可見斜裂縫、牆面材料剝落等損害。此為投影片案例描述，並非對其他建物的安全判定。

初步評估調整因子 Q1–Q4

因子條件與投影片數值
Q1 建造年代民國 63 年前（1974 前）：0.9；民國 64–72 年（1975–1983）：0.95；民國 73–88 年（1984–1999）：1.0；民國 89 年後（2000 後）：1.05；未知：1.0。
Q2 扭轉效應兩側街道立面皆有騎樓：0.9；單側街道立面有騎樓：1.0。
Q3 弱層效應有牆體中斷：0.9；無牆體中斷：1.0。
Q4 短柱效應投影片指出以一樓短柱（高度／深度比 < 2）占一樓柱總數的比例判定，並標示調整範圍 1 至 0.5；詳細分段應核對原始指引。

Q4 投影照片中未能清楚辨識完整分段公式，頁面保留可讀範圍與門檻描述，不補猜中間值。
